# API Documentation

The API contract will be maintained here.

- POST /api/auth/register
- POST /api/auth/login
- POST /api/emergencies
- GET /api/emergencies
- GET /api/emergencies/{id}
- PATCH /api/emergencies/{id}/status
- GET /api/ambulances
- PATCH /api/ambulances/{id}/status
- GET /api/hospitals
- POST /api/trips
- GET /api/trips/{id}
- GET /api/routes
